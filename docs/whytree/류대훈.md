# WhyTree — 말로일기

- 이름: 류대훈
- 날짜: 2026-10-28
- 제품: 말로일기 — 하루를 말로 남기고, 잘못 기록된 내용도 말로 고쳐 완성하는 일기 앱
- 대상: 일기를 쓰다 반복해서 멈췄고, 타이핑보다 말하기가 편한 직장인·자영업자

## 읽는 법

- 위로 갈수록 why(목적), 아래로 갈수록 how(방법)입니다.
- [씨앗] 지금 말로일기가 하는 일
- [새 방법] 아직 하지 않지만 How Down으로 새로 찾은 방법
- (점선) 부가적인 why로 이어진 연결. 표시가 없으면 실선(가장 중요한 why)입니다.

## Tree

- 성숙하고 단단한 사람으로 성장
  - 나를 이해하기
    - 온전히 내 일기
      - 내 뜻대로 남은 기록
        - 눈으로 확인하고 고치기
          - [씨앗] 음성을 글로 변환
    - 과거의 나 알기
      - 다시 읽는 재미와 의미
        - 히스토리 쌓기
          - (점선) [씨앗] 날짜별 저장
    - 나중에 쉽게 찾아보기
      - [씨앗] 날짜별 저장
      - [씨앗] 일기 기록 관리
    - 깊은 감정·생각 꺼내기
      - 깊이 있는 생각
        - 한 단계 더 생각하기
          - [씨앗] AI 질문으로 생각·감정 끌어내기
      - [새 방법] 생각 정리 음악·짧은 명상
  - 꾸준히 쌓인 기록의 가치
    - 꾸준히 쓰기
      - 부담 없이 기록하기
        - [씨앗] 말로 녹음
        - [새 방법] AI가 키워드를 기반으로 작성

## 메모

- "날짜별 저장"의 가장 중요한 why는 "나중에 쉽게 찾아보기"라서 실선입니다. "히스토리 쌓기"는 점선입니다.
