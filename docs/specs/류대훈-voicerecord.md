# Spec: 말로 녹음 → 글로 변환 (말로일기)

- 작성자: 류대훈
- 날짜: 2026-10-29
- 제품: 말로일기 — 하루를 말로 남기고, 잘못 기록된 내용도 말로 고쳐 완성하는 일기 앱
- 만든 방법: `/grill-me` 인터뷰(Matt Pocock skills)에서 정한 내용을 정리함
- 프로토타입 위치: `prototypes/류대훈/`

## 1. 누구를 위한 기능인가

- 하루를 기록하고 싶지만 일기 습관을 들이기 부담스러운 바쁜 사람
- 처음 써 볼 사람은 주변 직장인으로 좁힌다.

## 2. 문제가 생기는 순간

- 약속이나 늦은 퇴근 이후 집에서, 적은 힘을 들여 오늘 하루를 정리하고 싶을 때
- 이때 글을 쓰고 문장을 다듬는 부담 때문에 일기를 미룬다.

## 3. WhyTree에서 이 기능이 돕는 노드

- `부담 없이 기록하기` ← [씨앗] 말로 녹음
- `눈으로 확인하고 고치기` ← [씨앗] 음성을 글로 변환
- 참고: `docs/whytree/류대훈.md`

## 4. 사용자가 하는 일 (단계별)

1. 웹페이지를 연다. 이번 달 달력이 보인다.
2. 달력에서 날짜를 누른다. 오늘과 지난 날짜만 고를 수 있다. 미래 날짜는 누를 수 없다.
3. 그 날짜에 저장된 일기가 있으면 글 칸에 보인다.
4. 녹음 버튼을 누르고 말한다. 다시 누르면 녹음이 끝난다.
5. 녹음을 3분 하면 자동으로 멈춘다. 화면에 "3분이 지났어요. 더 말하려면 버튼을 다시 누르세요"가 뜬다.
6. 말한 내용이 글로 바뀌어 글 칸에 들어간다. 이미 글이 있으면 그 뒤에 이어 붙는다.
7. 사용자가 글 칸에서 글을 눈으로 확인하고, 틀린 곳을 손(키보드)으로 고친다.
8. 저장 버튼을 누른다. 글이 그 날짜에 저장된다.
9. 같은 날 다시 녹음하면 4~8을 반복한다. 새 글은 앞 글 뒤에 이어 붙는다.

## 5. 우선순위

| 우선순위 | 항목 |
|---|---|
| P0 (반드시) | 한 달 달력 화면, 날짜 선택(오늘과 지난 날만) |
| P0 | 녹음 버튼 하나로 시작/끝 |
| P0 | 최대 3분, 넘으면 자동 정지와 안내 문구, 다시 누르면 이어서 녹음 |
| P0 | 음성을 글로 변환해서 글 칸에 표시 |
| P0 | 같은 날 다시 녹음하면 앞 글 뒤에 이어 붙이기 |
| P0 | 글 칸에서 손으로 고치기 |
| P0 | 저장 버튼으로 그 날짜에 저장(브라우저 저장소) |
| P0 | 실패했을 때 안내 문구 3개 (7번 항목) |
| P1 (시간 되면) | 달력에서 일기가 있는 날 표시 |
| P2 (나중에) | AI가 문장·제목 정리 |
| P2 | 말로 고치기 |
| P2 | 검색('생일'처럼 단어로 일기 찾기) |

## 6. 범위 밖 (이번에 하지 않음)

- 다른 기기 간 동기화, 로그인. 저장은 그 기기의 그 브라우저에서만 보인다.
- AI 문장·제목 정리 (P2)
- 말로 고치기 (P2)
- 녹음 파일(음성 원본) 저장. 글만 저장한다.

## 7. 사용하는 AI 모델과 실패했을 때

- 음성 인식: 브라우저 내장 음성 인식(Web Speech API), 언어는 한국어(`ko-KR`)
- 지원 브라우저: Chrome(PC·Android), Safari(Mac, iPhone iOS 14.5 이상). Edge와 Firefox는 지원하지 않는다.
- API 키를 쓰지 않는다. 그래서 `.env`나 키 유출 위험이 없다.
- 실패하면 글 칸은 그대로 쓸 수 있다. 사용자는 휴대폰 키보드의 마이크 버튼으로 대신 말하거나 직접 칠 수 있다.

| 경우 | 화면 안내 문구 |
|---|---|
| 지원하지 않는 브라우저 | "이 브라우저에서는 녹음이 안 돼요. Chrome이나 Safari를 쓰거나, 아래 칸에서 키보드 마이크로 말해 주세요." |
| 마이크 권한 거부 | "마이크 권한이 필요해요. 브라우저 설정에서 허용해 주세요." |
| 인식된 말이 없음 | "들리지 않았어요. 다시 눌러 말해 주세요." |

## 8. 직접 해 볼 확인 (손으로)

1. 노트북 Chrome에서 오늘 날짜를 고르고 30초 동안 말한다. 말한 내용이 글 칸에 글로 나오는지 확인한다.
2. 글을 손으로 한 군데 고치고 저장한다. 새로고침한 뒤 같은 날짜를 눌렀을 때 고친 글이 그대로 있는지 확인한다.
3. 같은 날 한 번 더 녹음한다. 새 글이 앞 글 뒤에 이어 붙는지 확인한다. 이때 3분 동안 말해서 자동 정지와 안내 문구도 함께 확인한다.
