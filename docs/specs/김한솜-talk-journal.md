# Talk-Journal

> 말로 대화하듯 일기를 쓰면서 내 감정을 더 잘 알아차리게 해 주는 기능

## 누구를 위한 기능인가
- 대상: 하루를 돌아보고 싶지만 글로 쓰기는 귀찮고, 내가 느낀 감정이 정확히 뭔지 잘 모르겠는 사람. 지금은 나 혼자 쓰고, 나중에 일반 사용자에게 공개한다.
- 문제가 생기는 순간: 밤에 하루를 정리하려는데 빈 일기장 앞에서 무엇을 써야 할지 막힐 때. "그냥 기분이 별로야"에서 더 나아가지 못하고, 왜 그런지, 정확히 어떤 감정인지 말하지 못할 때.

## WHY TREE 연결
- 해당 노드: **나를 이해하기 → 친구와 대화하기**
  - 혼자서는 감정을 깊이 들여다보기 어렵다. 친구처럼 들어 주고 되묻는 상대가 있으면 내 감정을 말로 꺼내고 이름 붙일 수 있다.
  - AI는 호기심 많은 친구처럼 공감하고, 구체적인 장면을 묻고, 감정은 단정하지 않고 "~인 것 같은데, 맞아?"처럼 확인한다.
  - 지난 일기를 기억해 "지난번에 말한 그 일은 어떻게 됐어?"처럼 이어서 묻는다.

## 사용자가 할 수 있는 것 (단계별)
1. 이메일 매직 링크로 로그인하고 "오늘의 대화"를 시작하면, AI가 먼저 "오늘 하루 어땠어?"라고 묻는다.
2. 마이크 버튼을 누르고 말로 답한다. 말한 내용은 텍스트로 받아써지고 음성 파일은 삭제된다. AI는 공감 한마디와 함께 꼬리 질문 하나로 답한다. 이 과정을 원하는 만큼 반복한다.
3. "오늘은 여기까지"를 누르면 AI가 대화를 바탕으로 1인칭 일기와 감정 태그 제안(예: 불안 4, 서운함)을 만든다.
4. 일기와 감정 태그를 확인하고 고친 뒤 저장한다.
5. 일기 목록(날짜별, 대표 감정 표시)에서 지난 일기를 열어 정리본을 읽고, 필요하면 원본 대화를 펼쳐 본다. 정리본과 감정 태그는 나중에도 고칠 수 있고, 원본 대화는 고칠 수 없다.

## 우선순위
- P0 (꼭 출시):
  - 음성 입력과 받아쓰기, 텍스트로 답하는 턴제 대화
  - 친구 성격 대화 규칙(질문은 한 번에 하나, 감정은 단정하지 않고 확인)
  - 위험 신호 대응(자살예방상담전화 109, 정신건강위기상담 1577-0199 안내)과 "치료를 대신하지 않음" 안내
  - 1인칭 일기와 감정 태그(기본 감정 8~12개 + 강도 1~5 + 자유 단어) 생성, 확인 후 저장
  - 로그인, 일기 목록·상세·수정, 원본 대화 보관
  - 하루 여러 편 작성 가능
  - 사용량 상한(월 1~2만 원 이내)
- P1 (시간 되면):
  - 지난 일기를 기억하고 이어서 묻기
  - PWA(홈 화면에 추가)
- P2 (나중에):
  - 주간/월간 감정 흐름 그래프, 반복 패턴 분석
  - AI 답을 음성으로 읽어 주기(TTS)
  - 구글·카카오 로그인, 다국어 지원, 일반 공개

## 이번에 하지 않는 것 (Out of scope)
- 실시간 음성 통화식 대화(끼어들기)
- 음성 파일 보관과 다시 듣기
- 감정 그래프와 패턴 분석
- 내보내기, 알림
- 앱스토어 출시(네이티브 앱)
- 다른 사람과 일기 공유하기
- 상담이나 치료 기능

## AI 모델
- 사용 모델:
  - 대화, 일기 정리, 감정 태그 제안: Claude Sonnet 5.5
  - 음성 받아쓰기: OpenAI 받아쓰기 API
- 실패했을 때:
  - 받아쓰기 실패: "잘 못 알아들었어요"라고 알려 주고, 다시 말하거나 직접 타이핑할 수 있게 한다.
  - 대화 응답 실패: 내가 한 말은 화면에 그대로 남기고 "다시 시도" 버튼을 보여 준다. 대화가 사라지면 안 된다.
  - 일기 생성 실패: 원본 대화를 먼저 저장해 두고, 나중에 "일기 다시 만들기"를 할 수 있게 한다.
  - 사용량 상한 도달: 오늘은 텍스트로만 기록할 수 있다고 안내한다.

## 직접 해보는 확인 (2~3개)
1. 대화 느낌: 휴대폰에서 실제로 오늘 있었던 일을 3~4번 주고받는다. AI가 질문을 한 번에 하나만 하는지, 감정을 단정하지 않고 "~인 것 같은데 맞아?"처럼 묻는지, 친구 같다고 느껴지는지 확인한다.
2. 일기와 감정 정확도: 대화를 마친 뒤 1인칭 일기가 내가 한 말을 왜곡하지 않았는지 원본 대화와 대조한다. 제안된 감정 태그가 실제 내 감정과 맞는지, 고친 내용이 제대로 저장되는지 확인한다.
3. 위험 신호와 실패 상황: 힘든 감정을 담은 문장을 넣어 보고 AI가 진지하게 받아 주며 도움 창구를 안내하는지 확인한다. 네트워크를 끊은 상태에서는 내가 한 말이 사라지지 않고 "다시 시도"가 뜨는지 확인한다.

## 기술 구성 (참고)
| 영역 | 선택 |
|---|---|
| 앱 형태 | Next.js 웹앱(PWA), Vercel 배포 |
| 음성→텍스트 | OpenAI 받아쓰기 API (변환 후 음성 삭제) |
| 대화·일기 생성 | Claude Sonnet 5.5 |
| 저장·로그인 | Supabase, 이메일 매직 링크, 사용자별 보안 규칙(RLS) |
| 언어 | 한국어 (화면 문구는 한곳에 모아 관리) |
