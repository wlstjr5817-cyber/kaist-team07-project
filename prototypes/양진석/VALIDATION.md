# HW6 P0 검증 기록 — 양진석

검증일: 2026-10-29. 아래 에이전트 검증은 과제의 본인 수동 검사를 대신하지 않는다.

## 에이전트 검사

- P0 자동 검사 **16개 통과**: 구간 추가·순서, 성공/실패 대체, 전사 대기 후 종료, 빈 입력, 긴 글 일부 정리 실패 시 전체 원문 보존, 사용자 편집을 사용한 재정리, 실제 API 요청 형식, 키·인증 오류 처리.
- 녹음 타이머 모의 검사: 179,999ms까지 녹음, 180,000ms에 해당 구간 정지와 종료음 호출 1회, 마이크 트랙 종료·음성 버퍼 해제, 다음 구간 재시작 확인. 실제 휴대폰 소리 검사는 별도다.
- IndexedDB 모의 구현 검사: 새 음성 파일 없이 최종 본문·날짜와 기존 보관함 호환 메타데이터 저장, 저장 모듈을 다시 열었을 때 같은 글 반환, 빈 글 차단, 트랜잭션 중단 시 저장 실패, 검사/개인 저장소 분리.
- 기존 앱 회귀 검사 **86개 통과**, TypeScript 검사 통과, 배포용 Worker 빌드 성공. 현재 홈은 사진·검색을 포함한 기존 화면이며 새 작성 화면을 연결했다.
- 배포된 사이트에서 합성 WAV를 실제 `gpt-transcribe`로 변환했다. 결과: “오늘 친구랑 산책해서 기분이 좋았어. 호주 여행에서 바다를 봤던 순간이 생각났어.”
- 다음 구간의 음성 인식 실패를 재현했고, 첫 구간의 글과 실패 구간 표시·진행 선택 안내가 유지되는 것을 브라우저에서 확인했다.
- 문장 정리 실패를 재현했고, 원문이 편집 가능한 상태로 남는 것을 확인했다.
- 실제 `gpt-6-luna` 호출에서 임시 예제의 “음…”, “어…”는 제거되고 “진석”, “을지로”, “편했어”, “필요했나 봐”, “아, 진짜 좋았어”는 유지됐다. 한 예제의 결과이며 모든 음성·문장의 정확성을 보장하지 않는다.
- 저장 실패를 재현했을 때 오류 안내와 편집 본문이 남는 것을 브라우저에서 확인했다.
- 새 화면과 녹음 화면을 좁은 브라우저 너비에서 확인했다. 기존 서비스워커가 이전 모듈을 유지하는 상황을 발견해 새 작성 화면 자원은 온라인에서 최신 파일을 먼저 받도록 수정했다.

## 검증의 한계

- 실물 휴대폰 마이크·실제 3분 대기·종료음, 백그라운드/잠금 화면의 기기별 동작은 에이전트가 확인하지 않았다.
- 초기 버전의 브라우저 저장 성공·새로고침 검사는 JavaScript 확인 창에서 멈췄다. 이번 복원에서는 작성 취소를 화면 안 확인으로 바꾸었다. 저장 성공·다시 읽기·실패·검사 데이터 분리는 위 자동 검사에서 확인했다. 실제 휴대폰 검사는 아래에 남겨 둔다.
- 시험용 합성 음성은 실제 마이크 사용 검사를 대신하지 않는다.

## 양진석 본인이 수행한 검사 — 실행 완료·통과

실행일: 2026-10-29. 환경: 본인 휴대폰 · Safari. 양진석이 검사 3개 모두 직접 실행하고 정상 동작했다고 보고함. 기종·브라우저 버전 및 구체적인 실패 재현 조작은 별도 보고되지 않음.

| 검사 | 본인이 확인할 것 | 결과 |
|---|---|---|
| 1 | 30초 미만으로 말하기 → 초안 확인 → 이름 수정 → 저장 → 같은 휴대폰 브라우저에서 다시 열기 → 사진 추가 → 본문 검색으로 재확인 | 통과 (본인 확인) |
| 2 | 실제 3분 후 소리·화면 안내 → 이어서 녹음 → 전체 3분 이상을 한 일기로 저장 | 통과 (본인 확인) |
| 3 | 전사 실패 → 기존 글 확인 → 다시 녹음/추가 녹음 → 정리 실패 후 직접 수정·저장 | 통과 (본인 확인) |

실행 환경과 본인 확인 결과를 명세서 9절에 반영했다. 추가 문제나 수정 사항은 보고되지 않았다.


## 사진·검색 복원 검사 (2026-10-29)

- 통합 자동 검사 104개 통과, TypeScript 검사 통과, 배포용 빌드 성공.
- 새 일기의 기존 저장소 기록, 본문 검색, 사진 메타데이터 유지, 과거 기록과 수정 내용 보존, 중복 이관 방지, 삭제 기록 재생성 방지, 저장 실패를 자동 검사했다.
- 로컬 브라우저에서 검사 전용 일기를 작성·저장하고 앱 아이콘을 검사 사진으로 첨부했다. ‘은행나무’ 검색 결과에 같은 일기와 사진 1장이 표시됨을 확인했다.
- 본인 실제 기록에는 검사 데이터를 추가하지 않았다. 개인 브라우저 데이터의 전체 실사 또는 실물 휴대폰 검사는 수행하지 않았다.
- 배포된 동일 주소에서도 실제 합성 음성 인식·AI 정리 → 초안 수정 → 저장 시 기존 상세로 이동 → 검사 사진 추가 → 새로고침 → 본문 검색 결과에 같은 일기와 사진 표시를 확인했다. 이 흐름은 개인 기록과 분리한 검사 저장소에서 실행했다.
